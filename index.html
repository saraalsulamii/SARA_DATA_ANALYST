SQL Server / SSMS

Sales Performance & MoM Growth

Analyzed operational sales transactions to calculate monthly revenue trends, Month-over-Month (MoM) growth percentages, and customer segmentation using CTEs and Window Functions. 

WITH MonthlySales AS (
  SELECT YEAR(SaleDate) Y, MONTH(SaleDate) M, SUM(TotalAmount) Revenue
  FROM Sales GROUP BY YEAR(SaleDate), MONTH(SaleDate)
)
SELECT Y, M, Revenue,
  LAG(Revenue) OVER (ORDER BY Y, M) Prev_Month
FROM MonthlySales;

Data Cleaning & Transformation

Cleaned raw datasets by imputing missing values, standardizing datetime fields, splitting text strings, and removing duplicate records via `ROW_NUMBER()` window functions. 

WITH DuplicatesCTE AS (
  SELECT *, ROW_NUMBER() OVER (
    PARTITION BY CustomerID, SaleDate ORDER BY UniqueID
  ) AS row_num
  FROM RawSalesData
)
DELETE FROM DuplicatesCTE WHERE row_num > 1;
